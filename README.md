# 회원 관리 테이블 프로젝트

회원 목록을 관리할 수 있는 테이블 애플리케이션입니다. 필드 타입별 커스터마이징이 가능하며, 확장성 있는 구조로 설계되었습니다.

## 요구사항 충족 현황

### 1. 기술 스택 요구사항 ✅
- React, TypeScript, AntD 필수 스택 사용
- 추가로 Zustand(상태관리), Zod(스키마 검증) 등 적절한 라이브러리 활용

### 2. 필드 타입 정의 ✅
- type, label, required로 구성된 필드 구현
- text, textarea, date, select, checkbox 타입 지원
- 타입 안전성이 보장된 구조

### 3. 텍스트 길이 제한 ✅
- text 타입: 20자 제한
- textarea 타입: 50자 제한
- Zod 스키마를 통한 검증 구현

### 4. 기본 필드 구현 ✅
- 6개 기본 필드 모두 구현 완료
  - 이름 (text)
  - 주소 (text)
  - 메모 (textarea)
  - 가입일 (date)
  - 직업 (select)
  - 이메일 수신 동의 (checkbox)

### 5. 커스텀 필드 확장성 ✅
- 추상화된 타입 시스템 구현
- 재사용 가능한 컴포넌트 설계
- 검증 로직 분리를 통한 확장성 확보

### 6. 테이블 기능 ✅
- 필드별 컬럼 자동 생성
- 필드별 필터링 기능 구현
- 타입별 렌더링 처리
- 레코드 수정/삭제 기능

### 7. 스토리지 관리 ✅
- STORAGE 환경변수에 따른 스토리지 전환
- local-storage 모드에서 데이터 영속성 지원
- 날짜 데이터의 직렬화/역직렬화 처리

### 8. UI/UX ✅
- Figma 디자인 준수
- 모던한 UI 컴포넌트 구현
- 반응형 디자인 적용
- 모달을 전역 포탈로 구현하여 접근성 향상
- CSS 클래스 기반의 일관된 스타일 시스템 구축
- 폼 유효성 검사 기반의 버튼 활성화로 UX 개선

## 구현 내용

### 1. 기본 구조
- React + TypeScript + Ant Design 기반 설정
- Vite를 사용한 개발 환경 구성
- 덕스 패턴을 활용한 상태 관리 구조

### 2. 데이터 관리
- Zustand를 활용한 상태 관리
- Field, Record, FieldValue 등 타입 시스템 정의
- local-storage와 in-memory 스토리지 전환 구현
- 날짜 데이터의 직렬화/역직렬화 처리
- Zod를 활용한 필드 유효성 검증
  - 필드 타입별 검증 스키마 정의
  - 타입 안전성이 보장된 검증 로직
  - 커스텀 필드 확장성 고려

### 3. UI 컴포넌트
#### 공통 UI 컴포넌트 (`shared/ui`)
- Table: 일반적인 테이블 컴포넌트
  - 페이지네이션
  - 행 선택
  - 모달 통합
- Form: 일반적인 폼 컴포넌트
  - 폼 상태 관리
  - 제출 처리
  - 초기값 설정
  - 필드 렌더링 확장 포인트 제공
  - Zod 기반 유효성 검증 통합
  - 취소/제출 버튼 UX 개선
    - 취소 버튼으로 모달 닫기
    - 유효성 검사 기반 제출 버튼 활성화
- Modal: 전역 포탈 기반 모달
  - React Portal을 활용한 접근성 개선
  - 일관된 스타일 시스템 적용

#### 도메인 특화 컴포넌트 (`app/members/ui`)
- MembersTable: 회원 목록 테이블
  - 피그마에 고정된 컬럼 너비 적용 ('이름': 120px, '가입일': 200px, '이메일 수신 동의': 150px)
  - 필드별 필터링 기능
  - 체크박스 실시간 업데이트
- MemberForm: 회원 정보 입력/수정 폼
  - 필드 타입별 입력 컴포넌트 렌더링
  - 스키마 기반 유효성 검사
    - text 타입: 20글자 제한
    - textarea 타입: 50글자 제한
    - date 타입: dayjs 객체 검증
    - select 타입: 옵션 유효성
    - 필수 필드 검증

### 4. 스토리지 관리
- STORAGE 환경변수에 따른 저장소 전환
  - local-storage: 브라우저 새로고침 후에도 데이터 유지
  - in-memory: 메모리 상에서만 데이터 관리
- Zustand persist 미들웨어를 활용한 상태 지속성 관리

### 5. 날짜 처리
- dayjs를 활용한 일관된 날짜 포맷팅
- 'YYYY-MM-DD' 형식 적용
- Date 객체 변환 및 저장소 직렬화 처리

## 프로젝트 구조

```
src/
├── app/                    # 애플리케이션 메인 컴포넌트
│   └── members/           # 회원 도메인
│       └── ui/            # 회원 도메인 UI 컴포넌트
│           ├── MemberForm.tsx     # 회원 폼 특화 로직
│           └── MembersTable.tsx   # 회원 테이블 특화 로직
├── shared/                # 공유 컴포넌트 및 유틸리티
│   ├── ui/               # UI 컴포넌트
│   │   ├── Form.tsx     # 일반적인 폼 컴포넌트
│   │   └── Table.tsx    # 일반적인 테이블 컴포넌트
│   ├── types/           # 타입 정의
│   │   └── field.ts    # 필드 관련 타입 정의
│   ├── schemas/         # 스키마 정의
│   │   └── field.schema.ts  # 필드 검증 스키마
│   ├── utils/           # 유틸리티
│   │   └── validation.ts    # 검증 유틸리티
│   └── styles/           # 스타일 파일
└── store/                # 상태 관리
```

## 시작하기

### 필수 요구사항

- Node.js 18.0.0 이상
- pnpm 8.0.0 이상

### 설치 및 실행

```bash
# 의존성 설치
pnpm install

# 개발 서버 실행 (in-memory 스토리지)
pnpm dev

# 개발 서버 실행 (local-storage 사용)
STORAGE=local-storage pnpm dev

# 개발 서버 실행 (in-memory 사용)
STORAGE=in-memory pnpm dev
```
